# 아트 목록 (11/27) — 지금 쓰는 그림과 바꾸는 방법

지금 게임 그림은 거의 **임시(더미)**다. 이 문서 순서대로 바꾸면 체감이 큰 것부터 좋아진다.
그림 밑에 깔고 그릴 **가이드**는 `docs/art_guides/`(캔버스 칸, 가운데 노란 십자, 판정 원). 게임에는 들어가지 않는다.

## 1. 공통 규칙 (꼭 지키기)

- **도트(픽셀 아트)**, 투명 배경 **PNG**. 흐림(안티앨리어싱)·반투명 테두리 없이.
- 게임 화면은 **가로 180 × 세로 320 픽셀**. 그림 1픽셀 = 화면 1칸(PPU 16). 키울 때는 코드가 **정수 배(1, 2배)**로만 키운다.
- 테두리는 짙은 남색(예: `#221E2E`) 1픽셀로 두르면 우주 배경에서 잘 보인다.
- 팔레트는 30색 안팎으로 묶기 추천(자유롭게 쓸 수 있는 공개 팔레트를 골라도 됨). 몬스터는 생물 느낌, UFO는 금속·불빛, 운석은 돌, 다이아는 흰·하늘빛.
- **크기를 바꾸고 싶으면 먼저 말해 주기**(판정 크기·위치를 코드에서 같이 맞춰야 함).
- 다른 게임·작품의 캐릭터를 따라 그리지 않기(느낌만 참고).
- 무료 도트 도구 예: Aseprite(유료, 소스로 직접 빌드하면 무료), LibreSprite, Pixelorama, Piskel.

## 2. 바꾸는 방법

1. **같은 파일 이름·같은 크기로 덮어쓰기**가 가장 쉽다(연결이 그대로 유지됨).
2. Unity 창을 누르고 메뉴 **Bouncy UFO → Build All Scenes**.
3. `Assets/Art/Temp/Character/`, `Assets/Art/Temp/Items/`, `Assets/Art/Character/` 안의 그림은 도트 설정이 **자동**(PPU 16, 흐림 없음). 다른 폴더 그림은 Unity에서 Filter Mode = Point, Compression = None, PPU = 16 확인.
4. 크기·칸 배치가 달라지거나 새 그림이 추가되면 알려 주면 연결해 줌.

### 코드로 그리는 것(그림 파일이 없음, 바꾸려면 말해 주기)
- **지구**(자전하는 공): 256×128 세계 지도 한 장을 그려 주면 그 그림으로 돌게 바꿀 수 있음(왼쪽 끝과 오른쪽 끝이 이어지게).
- 파편·충격파·조이스틱·별 반짝임, 앱 아이콘(지구 그림이 바뀌면 다시 만듦).

## 4. 추천 순서

1. UFO 3~4종 → 2. 몬스터 3종(기본 색 1개씩 먼저) → 3. 운석 2종 → 4. 캐릭터 몸통·머리 1쌍·눈 1·옷 1 → 5. 보스 → 6. 마을 건물·꾸밈 → 7. 아이콘들.
한 단계씩 넣고 게임에서 보면서 크기·색을 맞추는 걸 추천.
