## Play Console 확인 결과 (2026-11-24, 읽기만 함)

- 개인 계정이고 앱이 1개 있습니다: 「항해하는 갈매기」(Unity 게임으로 보임). 마지막 업데이트 2025-07-27, 현재 **Google Play에서 삭제된 상태**(2026-06-10).
- 삭제 사유: **기기 및 네트워크 악용 정책 위반** (앱에 사용자 정보 노출·기기 손상 가능성이 있는 보안 취약점). 해결 방법 안내에 Unity 토론 링크가 있어 Unity 엔진의 보안 취약점으로 보임. 같은 유형의 경고가 2025-10, 2026-01, 2026-04에 있었고, 이의신청은 하지 않은 상태로 확인됨.
- 같은 앱은 2026-08-31부터 Android 16(API 36) 미만 타깃으로 업데이트가 거부되는 상태.
- **판매자 상태 선언**이 필요합니다. **2027년 2월까지** 선언하지 않으면 개발자 프로필과 앱이 전 세계 Google Play에서 삭제된다고 안내됨. 홈 화면에 '조치 필요'로 표시.
- 휴면 계정 경고(조치 기한 2027-01-04)도 별도로 표시됨.

## 기존 DefendEarth 프로젝트 확인 (2026-11-26)

- Unity 6000.3.10f1 → CVE-2025-59489는 해결됐지만 Brotli 취약점 범위. 새 프로젝트는 6000.3.29f1로.
- Android 패키지명 미설정, Target API "자동", IL2CPP·ARM64 정상, 화면 자동 회전.
- 사용자 PC C:\DE\DefendEarth = GitHub 저장소와 동일(247개 파일).

## Android 개발자 인증 (2026-11-24 공식 문서 확인)

- Google Play에 올리는 앱은 Play Console 계정으로 자동 등록되고, Play 앱 서명을 쓰면 Google이 소유권 정보를 보유한다.
- 미등록 앱은 인증된 기기(Android 8 이상)에 설치되지 않는다. 2026-09-30에 브라질·인도네시아·싱가포르·태국부터 시행, 2027년 전 세계 확대.
- Play 외부 배포용 추가 서명 키는 이번 게임에서는 필요 없다. 첫 업로드 후 Play Console의 Android 개발자 인증 페이지에서 "등록됨"인지 확인한다.

## 새 게임에 반영할 규칙

- Unity는 **보안 취약점 수정이 포함된 최신 패치 버전**을 사용하고, 빌드할 때마다 Play Console 경고가 없는지 확인한다.
- 같은 위반이 반복되면 계정 해지로 이어질 수 있으므로 새 게임 출시 전에 이 문제가 재발하지 않게 한다.
- 2027년 2월 전에 판매자 상태 선언을 끝낸다.

## 11/27 앱 권한: 진동(VIBRATE) 추가 (사용자 승인)

- 타격감(맞음·처치·보스·지구 피해) 폰 진동을 위해 `android.permission.VIBRATE`를 넣는다. Unity가 코드의 `Handheld.Vibrate` 참조를 보고 자동으로 넣는다(`Core/Haptics.cs`).
- 위험 권한이 아니라 사용자에게 묻는 창은 뜨지 않는다. 설정의 "진동"으로 끌 수 있다.
- 실제 진동은 안드로이드 진동기를 직접 불러 짧게(18~120ms)·세기를 정해 울린다.
