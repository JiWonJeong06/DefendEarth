# 게임 개발 일정 (Google Play 출시 목표) - 2026-11-26 수정본

목표: Google Play 스토어에 「통통 UFO / Bouncy UFO」(패키지명 `com.kkangjung.bouncyufo`) 출시.
작업 분담: 기획·아트 프롬프트는 Cowork, 코드 개발·구현은 Claude Code (「Google Play 앱·게임 출시 지침서」의 작업 분담 서약 참고)
게임 내용: 「탄막슈팅 기획 초안」(우주선 몬스터 방어 슈팅, 무한 방식).

## 0. 일정을 바꾼 이유

Play Console 정책 상태에 **휴면 계정 경고**가 떠서 **2027-01-04까지** 조치하지 않으면 개발자 계정이 해지되고 등록비도 환불되지 않습니다. 조치는 두 가지를 모두 완료해야 합니다.

1. 계정 세부정보에서 이메일과 전화번호 인증
2. 앱을 만들어 게시하거나, 기존 앱에 새 앱 번들(AAB)을 업로드

- Google 문서는 내부·비공개 테스트에 올리는 것을 "일반에 공개하지 않고 안전하게 업로드하는 방법"으로 안내하지만, 테스트 트랙 업로드만으로 조건이 충족되는지는 **문서에 명시돼 있지 않습니다.** 정책 상태 화면의 '시행 절차 자세히 알아보기'와 경고 메일의 안내를 확인합니다.
- 게임 완성본을 1월 4일까지 출시하는 것은 현실적으로 어렵습니다. 대신 **게임의 초기 빌드를 12월 중순에 비공개 테스트로 올려** 휴면 해제와 비공개 테스트 14일 요건을 동시에 해결합니다.

## 1-1. 개발이 예상보다 빠를 때 (11/26, 사용자 요청)

개발 속도가 생각보다 빠를 수 있다. 그때는 아래 순서로 앞당긴다.

1. **첫 빌드가 일찍 되면 비공개 테스트도 일찍 시작한다.** 12/18을 기다리지 않는다. 일찍 올릴수록 휴면 계정 경고 해제가 빨라지고, 14일 연속 테스트도 일찍 끝나 프로덕션 액세스를 빨리 신청할 수 있다. (테스터 모집을 그만큼 먼저 끝내 둔다)
2. **1월 작업을 앞으로 당긴다.** 우선순위: ① 판 밖 성장(골드 사용처) → ② UFO 3종·몬스터 추가 → ③ 전체 튜토리얼 → ④ Google Play 게임즈(순위표·클라우드 저장) → ⑤ 캐릭터 꾸미기 → ⑥ 3개 언어·효과음.
3. **출시도 2/14보다 앞당길 수 있다.** 단, 14일 연속 테스트 + 프로덕션 액세스 심사 + 출시 심사 시간은 줄일 수 없으므로 그 기간을 빼고 계산한다.
4. 빨라져도 **줄이지 않는 것**: 보안 규칙(Unity 버전, targetSdk, 16KB, 릴리스 빌드), SDK 추가 전 확인, 데이터 보안 신고·개인정보처리방침, 실제 폰 테스트, 단계적 출시.
5. 남는 시간은 새 기능보다 **재미 다듬기**(손맛, 난이도 곡선, 연출)에 먼저 쓴다. 기존 게임이 "돌아가지만 재미없었던" 문제를 되풀이하지 않기 위해.

## 2. 핵심 기한

- **2026-12-18 (권장 목표)**: 초기 빌드를 비공개 테스트에 업로드하고 테스터 참여 시작. 이 날 시작하면 14일 연속 조건이 2027-01-01에 충족됩니다.
- **2026-12-28 (최종 안전선)**: 휴면 경고의 7일 전 알림이 오는 시점입니다. 이때까지 인증과 업로드를 끝냅니다.
- **2027-01-04**: 휴면 계정 조치 기한. 넘으면 계정 해지.
- **2027-02-01**: 16KB 미지원 업데이트 출시 불가 시작.
- **2027-02 (판매자 상태 선언 기한)**: 선언하지 않으면 개발자 프로필과 앱 삭제.

## 3. 주의할 점

- **패키지명 `com.kkangjung.bouncyufo`는 한 번 정하면 바꿀 수 없습니다.** 앱 생성 때 이미 쓰이는 이름이면 다시 정합니다.
- 비공개 테스트에는 **실제로 만들 게임**을 올려야 합니다. 테스트 중에는 빌드를 계속 갱신할 수 있습니다.
- 테스터 12명은 14일 연속 참여해야 하므로 15~25명을 모집하고, 참여 시작 전에 미리 확보합니다.
- 조직 계정이면 12명 14일 요건은 없지만, 이메일·전화 인증과 앱 번들 업로드는 똑같이 필요합니다.
- 계정을 새로 만들면 비공개 테스트 요건이 다시 적용되므로 가급적 현재 계정을 유지합니다.
- Google Play 게임즈 연동은 출시 전 필수(사용자 결정). 1월 중순까지 붙여야 데이터 보안 신고까지 여유 있게 맞출 수 있습니다.
