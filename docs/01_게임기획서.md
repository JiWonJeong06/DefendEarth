## 게임 규칙 (무한 방식, 11/26)

| 항목 | 규칙 |
|---|---|
| 목표 | 최대한 오래 버티며 높은 점수 얻기. 클리어 없음 |
| 끝 | **지구 체력이 0이 될 때만** 끝난다. 시간 제한 없음 |
| 지구 피해 | 몬스터가 지구에 닿으면 그 몬스터의 공격력만큼 깎임 |
| 내 우주선 | 체력 없음. 맞아서 지는 일 없음 |
| 진행 | 웨이브 단위로 몬스터가 몰려오고, 시간이 갈수록 몬스터 수·체력·속도가 오르고 새 종류가 섞인다. 가끔 러시(동시 출현) |
| 보스 | **일정 간격마다 등장** (예: 2분 또는 N웨이브마다). 갈수록 강해지고 종류가 바뀜 |
| 점수 | 잡은 몬스터 + 버틴 시간(+ 보스 처치 보너스) |
| 보상 | 운석 골드(얻은 만큼) + 단계 보상 골드 |
| 기록 | 최고 점수 기기 안 저장, 결과 화면에 표시 |

- 기존 DefendEarth의 "시간이 갈수록 몬스터 체력·공격력 상승", "러시" 구조를 살린다. 기존 난이도 3단계 수치(쉬움→보통→어려움)는 무한 판의 시간대별 난이도 곡선 참고값으로 쓴다.
- 한 판 길이: 처음 하는 사람 3~5분, 잘하는 사람은 더 길게 버티도록 난이도 곡선을 잡는다.

## 몸통 박치기 (11/27 사용자 결정, 지금 규칙)

> 11/27 사용자 결정: 투사체(총알)를 쏘는 대신 UFO 몸통으로 몬스터를 튕겨 낸다. 이 절이 아래 「조작」「탄」, 우주선 무기 설명보다 우선한다.

- **조준·충전 (11/27 첫 테스트 후 변경)**: **게이지 없음 (11/27 사용자 결정)**: 오르내리는 게이지를 시험해 본 뒤 게이지를 아예 뺐다. 화면 아무 데나 꾹 누르고 **새총처럼 뒤로 당기면 반대쪽으로** 조준만 한다. 날아가는 세기는 늘 같고, 거리·사거리는 나중에 성장 요소로 늘린다. 위쪽 반원만(수평에서 최소 12° 위). 날아갈 길이 점선으로 미리 보인다. 거의 안 당기고 떼면 취소.
- **느낌 조정 (11/27)**: 너무 빨리 떨어져서 중력 1450 → 750. 게이지를 빼면서 돌진 속도는 460 하나로, 공격력이 세서 돌진 피해는 1(카드 돌진 힘으로 +1씩).
- **몬스터 등장 (11/27)**: 무리 없이 **한 마리씩**, 1웨이브 7 → 5마리(웨이브마다 +1), 러시 간격 0.35 → 0.8초.
- **지구 (11/27)**: 화면 아래를 꽉 채우는 큰 지구(반지름 150픽셀, 윗부분 44픽셀만 보임)가 스스로 돈다(90초에 한 바퀴). 몬스터는 둥근 표면에 닿을 때 지구 피해. 스프라이트 스태킹 대신, 평평한 지도를 공 모양에 감아 밀어 주는 방식(행성 자전에 더 맞음). 아트가 나오면 지도 그림만 바꾼다.
- **화면 꾸미기 (11/27)**: 로딩 화면은 가운데에서 지구가 자전하고, 로딩바와 **지구 체력 바**는 옛 UI 그림(틀·검정 안 채움·빨강 채움)을 옛 슬라이더처럼 Sliced로 늘려 쓰는 같은 막대(너비 130, 높이 16픽셀로 얇게). 위쪽에 **"WAVE 3"** 표시, 새 웨이브가 시작하면 화면 가운데에 크게 잠깐 뜬다. 게임 화면에도 반짝이는 별 배경. 몬스터는 같은 종류도 색이 여러 가지(떼거리형 4색, 돌진형 3색, 덩치형 3색)로 무작위로 나온다.
- **돌진**: 손을 떼면 조준한 쪽으로 날아가고, 중력으로 다시 땅(원래 높이)에 떨어진다. 벽·천장에 닿으면 튕긴다. **착지해야 다음 돌진**(공중에서 떼면 곧 착지할 때 바로 돌진).
- **피해는 날아가는 중에만**: 날아가는 UFO에 닿은 몬스터만 피해를 입고 위로 튕겨 나간다. 피해·튕기는 세기는 늘 같다. **가만히 서 있으면 몬스터가 그냥 통과**해 지구로 내려간다.
- **연쇄**: 튕겨 나간 몬스터가 다른 몬스터와 부딪히면 그 몬스터도 피해를 입고 튕긴다(최대 2단계).
- **UFO는 피해 없음**. 지구만 지키면 된다.
- **보스·덩치형**: 조금만 밀려 올라갔다 다시 내려온다. 여러 번 받아쳐야 한다(튕김 배율: 보스 0.25, 덩치 0.5).
- 판 안 카드 5장 (11/27): **돌진 힘**(피해 +1), **멀리 날기**(돌진 속도 +10%, 옛 빠른 충전 자리), **큰 몸통**(판정 +20%), **연쇄 충돌**(연쇄 피해 +1), **지구 회복**.
- 로비 강화: 옛 '연사 +5%' → 빠른 충전 → **멀리 날기 +4%**(저장된 단계는 그대로 이어짐).
- 몬스터 간격 규칙은 유지(가로 간격 = 플레이 영역 너비 8% 이상).
- **정할 것**: 우주선 종류(산탄형·관통형·채굴형·폭발형)는 무기 기준이라 몸통 박치기에 맞게 다시 정해야 한다.

## (옛 기록) 조작: 탭 한 칸 통통 이동 (11/26 변경)

> 11/26 첫 테스트 후 사용자 결정: 좌우 드래그(스와이프)를 없애고 통통 튀는 이동만 남긴다. 아래 옛 드래그·대시 설명은 기록용.

- **누르는 길이 = 튀는 거리 (11/26 추가 변경)**: UFO보다 왼쪽/오른쪽을 누르면 그쪽으로 통 튄다. **짧게 탭하면 조금**(플레이 영역 너비의 8%), **길게 누를수록 멀리**, **최대 거리 있음**(35%, 약 0.45초 누르면 최대). 손을 뗄 때 튀고, 누르는 동안 UFO가 납작하게 움츠리며 힘을 모으는 모양이 보인다. 멀리 튈수록 조금 더 높고 오래 튄다.
- **연타**: 튀는 중에 또 누르고 떼면 착지하자마자 이어서 튄다. 한 번에 손가락 하나만 인식한다. 재사용 대기는 없다.
- 벽에 붙어 있을 때 벽 쪽을 탭하면 제자리에서 살짝 움찔한다.
- 튀는 거리는 플레이 영역 비율이라 기기마다 같다. 드래그 감도 설정은 필요 없어졌다.

(옛 설명)

- **드래그 이동**: 화면 아무 데나 손가락을 대고 좌우로 밀면 우주선이 손가락이 움직인 만큼 따라간다(우주선을 직접 잡지 않음 → 손가락이 우주선을 가리지 않음, 엄지 한 손 플레이). 조이스틱은 없앤다. 이동은 **좌우만**.
- **자동 발사**: 지금처럼 계속 위로 쏜다.
- **탭 = 통통 대시**: 화면을 짧게 탭하면 탭한 쪽(우주선 기준 왼쪽/오른쪽)으로 **통 튀면서 짧게 순간 이동**한다.
  - 몬스터 떼가 몰려올 때 빠르게 자리를 옮기는 용도.
  - 짧은 재사용 대기시간(초기값 0.5초 정도)을 둬서 연타만으로 플레이하지 않게 한다.
  - 탭과 드래그 구분: 손가락을 짧게(약 0.15초 이내) 대고 거의 안 움직였으면 탭, 그 외는 드래그. (수치는 첫 빌드에서 손맛 보고 조정)
- **탄성 연출 (B)**: 움직이기 시작하거나 멈출 때 젤리처럼 늘었다 줄었다(스쿼시·스트레치), 발사할 때 살짝 들썩, 대시 착지 때 통 눌렸다 튀어 오름, 레벨업 때 크게 통 튐. 둥근 UFO 몸체라 이 연출이 특히 잘 어울린다.
- 나중에 판 안 강화로 "착지 충격파"(대시 착지 때 주변 작은 몬스터에 피해) 같은 대시 강화를 넣을 수 있다.

## 화면 (세로형, 공정성 11/26)

좌우 이동이 핵심인 게임이라, 폰마다 화면 크기·비율이 달라도 **유불리가 없어야** 한다. 비율로 해결한다. (무한 점수 경쟁이라 공정성이 더 중요하다.)

1. **기준 해상도**: 9:16, 도트는 180×320으로 그리고 6배 = 1080×1920. 특정 폰 기종을 기준으로 하지 않는다.
2. **플레이 영역 고정**: 게임 세계의 플레이 영역을 고정된 크기(180×320, 9:16)로 정하고, 어떤 화면이든 이 영역 **전체가 보이도록** 카메라를 맞춘다(화면에 들어가는 가장 큰 크기로). → 몬스터가 나오는 좌우 범위, 우주선 이동 범위, 몬스터가 내려오는 거리가 **모든 기기에서 똑같다.**
3. **남는 공간은 배경·UI로** (판정 없음):
   - **얇은 폰** (20:9, 21:9, 폴더블 바깥 화면 23:9 등): 가로에 꽉 맞추고 **위아래**에 여백. 예) 1080×2520이면 위아래 300px씩. 점수·지구 체력·골드·일시정지 버튼을 여기에 두면 플레이 영역을 가리지 않는다.
   - **넓은 화면** (태블릿, 폴더블 펼친 화면(갤럭시 Z 폴드8 4:3 등), 가로로 돌아간 창): 세로에 꽉 맞추고 **양옆**에 여백. 우주 배경·장식으로 채우고, 여백이 크면 UI를 옆으로 옮긴다.
   - 어느 쪽이든 더 많이 보이는 기기가 없으므로 공정하다.
4. **스와이프 감도를 비율로**: 손가락 이동을 픽셀이 아니라 **화면에 보이는 플레이 영역 너비 대비 비율**로 계산한다. 플레이 영역 너비만큼 밀면 어느 기기든 우주선이 끝에서 끝까지 간다.
5. **대시 거리·탄 크기·몬스터 속도**도 모두 플레이 영역 기준 단위로 정한다.
6. **설정에 감도 조절**(예: 0.7~1.5배)을 넣는다. 얇은 폰은 실제 손가락 이동 거리가 짧아 예민하게 느껴질 수 있어서.
7. 노치·펀치홀은 Safe Area로 피한다.
8. **화면 방향 주의 (Android 16 / API 36)**: 큰 화면(가장 짧은 변 600dp 이상: 태블릿, 폴더블 안쪽 화면)에서는 앱의 세로 고정·비율 제한이 무시될 수 있다. 게임 카테고리 앱은 예외로 되어 있지만(Unity의 게임 카테고리 설정 확인 필요), Android 17(API 37) 대응도 있으므로 **가로 창이 되어도 3번처럼 양옆 여백으로 정상 플레이되도록** 처음부터 만든다. 세로 고정에 의존하지 않는다(지침서 「코딩 수칙」).

- 남는 한계: 폰의 실제 크기(cm)가 달라 얇은 폰은 몬스터·우주선이 실제로는 조금 작게 보인다. 그래서 탄·몬스터를 처음부터 큼직하게 그린다.
- **테스트 해상도**: Unity Game 화면에 9:16(1080×1920), 20:9(1080×2400), 21:9(1080×2520), 23:9(폴더블 바깥 화면), 4:3(태블릿·폴드8 안쪽), 가로 창(16:10 등)을 추가해 확인. 실제 손맛은 본인 폰, 태블릿·폴더블은 Android 에뮬레이터, 저사양 성능은 비공개 테스트 참가자 폰과 Play Console 사전 출시 보고서로 확인. (무한 방식은 후반에 몬스터가 많아지므로 저사양 성능 확인이 특히 중요.)

## 탄 (Projectile, 11/26)

- 기존 탄은 너무 작아서 잘 안 보이고 맞는 느낌이 약하다. **눈에 확 띄는 크기로 키운다.**
- 크기 기준 (제안): 우주선 너비의 약 1/3~1/2. 기준 해상도 180×320에서 대략 6×10 픽셀 정도부터 시작해 첫 빌드에서 조정.
- **판정은 그림보다 살짝 크게**: 몬스터를 맞히기 쉬워야 쓸어 담는 쾌감이 난다.
- 탄 그림은 단순하고 밝은 색(배경·몬스터와 구분되는 색)으로. 맞으면 작은 튀김 효과와 몬스터가 살짝 하얗게 번쩍이는 연출.
- 판 안 강화에 **"탄 크기 증가"**를 넣으면 성장이 눈으로 바로 보인다. (기존처럼 레벨 구간마다 탄 그림이 바뀌는 연출도 살릴 수 있음)
- 몬스터의 침(적 탄)이 있다면 내 탄과 색·모양을 확실히 다르게 한다.

## 우주선 (11/26 확정)

원칙: 점수 경쟁 게임이므로 비싼 우주선이 그냥 더 센 구조가 아니라 **플레이 방식이 다르게** 만든다. 우주선마다 **기본 무기 하나 + 특성 하나**.

### 모양: UFO (11/26)
- 모든 우주선은 **UFO 모양**: 둥근 접시 몸체 + 위쪽 투명 돔. 탄은 돔(위쪽)에서 위로 쏜다.
- 위에서 내려다본 모습이 아니라 **옆에서 본 접시 실루엣**이 세로 화면 아래쪽에서 잘 읽힌다(가로로 넓고 납작). 판정은 몸체 크기 원형.
- 우주선끼리 구분은 **돔 모양·접시 테두리·아래 불빛 색·달린 장치**로 한다. 예: 기본형(둥근 돔, 기본 색), 산탄형(넓은 접시, 테두리에 발사구 3개), 관통형(뾰족한 돔, 긴 포신), 채굴형(아래에 집게·자석 장치), 폭발형(통통한 몸체, 큰 포구).
- 몬스터·운석과 한눈에 구분되게: 우주선은 금속·밝은 불빛 계열, 몬스터는 생물 느낌, 운석은 반짝이는 돌.
- 세계관 거리: "UFO = 지구 침략자"라는 흔한 이미지를 뒤집어 **지구를 지키는 UFO**로 하면 이야기 포인트가 된다(세계관은 사용자가 정함).
- 주의: 유명 게임·영화·캐릭터의 UFO(특정 고전 게임의 UFO 실루엣, 유명 외계인 캐릭터 등)를 닮지 않게 직접 디자인. UFO 모양 자체는 흔한 일반 형태라 괜찮다.

| 우주선 (가칭) | 기본 무기 | 특성 | 잘 맞는 상황 | 출시 시점 |
|---|---|---|---|---|
| 기본형 | 직선탄 1줄, 균형 | 없음 | 처음 시작용 | 12/17 첫 빌드 |
| 산탄형 | 부채꼴 3갈래, 한 발은 약함 | 탄 갈래 카드 효과 증가 | 떼거리형이 몰려올 때 | 1월 |
| 관통형 | 느리지만 강한 관통탄 | 덩치형에 추가 피해 | 단단한 몬스터, 일렬로 오는 적 | 1월 |
| 채굴형 | 약한 직선탄 | 운석 골드 증가, 운석 자석 | 골드를 모으고 싶을 때 | 1월 |
| 폭발형 | 느린 큰 탄, 맞으면 터짐 | 폭발 범위 증가 | 몬스터가 뭉쳐 있을 때 | 출시 후 |

- 같은 강화 카드도 우주선에 따라 궁합이 달라진다(산탄형 + 탄 갈래 카드 = 화면을 덮음 등).
- 기본형 외 우주선은 골드로 해금. 뽑기 없음.

### 우주선별 성장 (11/26 제안, 미확정)

각 우주선은 골드로 따로 키운다. 트랙 3개, 각 5단계, 단계마다 체감되게.

| 트랙 | 내용 | 예시 |
|---|---|---|
| 무기 강화 | 기본 무기의 공격력·연사 | 단계마다 공격력 +10% 정도 (5단계 합 +50% 이내) |
| 특성 강화 | 그 우주선만의 특성이 세짐 | 산탄형: 갈래 수/각도, 관통형: 덩치형 추가 피해, 채굴형: 운석 골드 %, 폭발형: 폭발 범위 |
| 시작 보너스 | 판을 조금 유리하게 시작 | 3단계: 시작 레벨 2, 5단계: 첫 카드 선택지 1장 추가(4장 중 1장) |

- **외형 변화**: 단계가 오르면 UFO에 불빛·테두리 장식이 늘어나고, 무기·특성 둘 다 5단계면 최종 외형(기존 DefendEarth의 "레벨마다 그림이 바뀌는" 연출을 살림).
- **지구 강화는 우주선과 별개로 공통**(지구 최대 체력, 시작 방어막).
- **공정성**: 판 밖 강화가 너무 세면 오래 한 사람만 점수가 높아진다. 다 키워도 처음보다 체감은 되지만 실력 차이를 뒤집을 만큼은 아니게(총합 상한을 둠).
- 가격은 단계마다 올라간다. 금액은 운석·단계 보상 골드량과 함께 밸런싱.

## 캐릭터 커스터마이징 (11/26 확정: 인간 모습, 프로필용)

- **모습**: 인간. UFO를 모는 조종사(파일럿) 느낌을 권장.
- **보이는 곳 (11/26 확정)**: **프로필 형태로만** 보인다(로비·프로필·결과 화면). **게임 중 UFO 돔 안에는 보이지 않는다**(돔 안에서는 뒷모습만 보여 의미가 없음).
- **효과**: 처음에는 게임에 영향 없음(점수 공정성 유지). 나중에 스탯을 붙이면 순위표 공정성에 영향 → 그때 효과를 아주 작게 하거나 순위표 판에서는 끄는 방식을 따로 정한다.
- **꾸미기 방식**: **정해진 부품 고르기**(머리 모양·머리색·얼굴·피부색·옷·모자/헬멧·액세서리 등). 플레이어가 직접 그리거나 자유 글을 써서 남에게 보이는 기능은 넣지 않는다(신고·검열 의무가 생김).
- **얻는 방법**: 골드 구매, 업적·기록 보상. 뽑기 없음. 유료 판매는 지금 없음(넣게 되면 결제 정책 확인 후 상의).
- **순위표 표시**: Google Play 게임즈 순위표에는 Google 게이머 프로필(닉네임·아바타)이 보이고, 우리 캐릭터는 보이지 않는다. 캐릭터는 게임 안 화면에서만 보인다.
- **디자인 주의**: 13세 이상 선언에 맞게 아이처럼 보이지 않는 톤(청소년~성인 조종사)으로. 실존 인물·유명 캐릭터를 닮지 않게. 피부색 등은 다양하게 고를 수 있게.
- 일정: 1월(PGS와 함께). 첫 빌드에는 없음.

## Google Play 게임즈 연동 (11/26 확정, 출시 전 완료)

- **용도**: 전 세계·친구 순위표(최고 점수). 나중에 업적·클라우드 저장도 같은 SDK로 가능(추가할 때 다시 상의).
- **로그인**: PGS 프로필로 자동 로그인. 게임 자체 계정을 만들지 않으므로 앱 내 계정 삭제 기능 의무는 생기지 않는다(출시 전 정책 재확인).
- **데이터 보안 신고 (출시 전 필수)**: PGS SDK가 게이머 프로필(닉네임·아바타), 게임 점수 등 게임 서비스 데이터, 분석·진단 정보를 수집한다. Play Console 데이터 보안 항목과 개인정보처리방침에 사실대로 반영. 사용하는 기능(순위표만, 업적, 저장 등)에 따라 항목이 달라지므로 붙일 때마다 다시 확인. (참고: developer.android.com/games/pgs/data-collection)
- **서버 필요 없음**: 순위표 저장·정렬·전체/친구/기간별 순위는 Google이 운영. 게임은 판 끝에 점수를 보내고, Google 순위표 화면을 열기만 한다. 서버가 필요해지는 경우(자체 디자인 순위표에 우리 캐릭터 표시, 서버 검증으로 조작 완전 차단)는 지금 기획에 없음.
- **Play Console 설정 (사용자와 함께)**: 게임즈 서비스 생성, 앱 서명 키 정보 연결, 순위표 생성. 서명 키를 다루므로 작업 전 확인받고 진행.
- **SDK 버전**: 최신 Play Games 플러그인(Unity v2) 사용, 16KB 페이지 크기 지원 확인(Claude Code에서 붙일 때). SDK 추가 시 지침서 규칙대로 멈추고 확인.
- **점수 조작 대비**: 점수는 폰에서 보내는 값이라 조작될 수 있다. 말이 안 되는 점수(시간 대비 너무 높은 점수 등)는 보내지 않는 확인 장치를 넣고, Play Console의 순위표 조작 방지 관련 설정을 확인한다.
- 일정: 1월 연동 → 1/31 출시 후보 전에 데이터 보안 신고까지 맞춤.

## 튜토리얼 (11/27 사용자 결정: 따로 만든 튜토리얼, 지금 규칙)

처음 게임을 시작하면(또는 설정의 "튜토리얼 다시 보기" 뒤) 웨이브 대신 정해진 순서로 진행하는 튜토리얼 판을 한다. 코드: `UI/TutorialDirector.cs`.

- **보여 주는 방식**: 설명할 때마다 게임을 멈추고, 설명할 대상(UFO·몬스터·운석·보스)을 노란 네모로 강조하고 나머지는 어둡게 한다. 글 상자에 한 글자씩 타이핑(타자 소리)하고, 화면을 누르면 다 보이기 → 다음 줄. 직접 해 볼 때는 어둡게 하지 않고 노란 네모와 짧은 안내만 남긴다.

| 단계 | 안내 | 넘어가는 조건 |
|---|---|---|
| 1. 조작법 | UFO 강조: 꾹 누른 채 뒤로 당기기 → 반대쪽으로 날아감 → 점선 = 날아갈 길 → 떼면 날았다가 내려옴 | 직접 두 번 날기 |
| 2. 떼거리형 | 처음 나타나면 멈추고 강조: 날아가는 UFO에 부딪힌 몬스터만 피해, 서 있으면 통과, 지구에 닿으면 체력 감소 | 처치(놓치면 다시) |
| 3. 돌진형 | 멈칫했다가 빠르게 내려옴, 멈칫할 때를 노리기 | 처치(놓치면 다시) |
| 4. 덩치형 | 튼튼하고 잘 안 밀림, 지구 피해 큼 | 처치(놓치면 다시) |
| 5. 골드 운석 | 부수면 골드(로비 강화에 씀), 지구엔 피해 없음, 놓치면 골드도 사라짐 | 부수거나 놓침 |

  - **전면광고**: 판이 끝난 뒤 결과 화면 같은 자연스러운 쉬는 지점에서만, 횟수 제한(예: 3판에 1번), 닫기 버튼 분명히. 재미를 해치기 쉬워 비추천.

### 골드 (11/26 확정)

**1) 재화 운석**
- 판 중에 **재화 운석**이 몬스터 사이에 섞여 몬스터와 비슷한 속도로 떨어진다. **부숴야 골드**를 얻는다. 기존 "점수의 35% → 골드"는 없앤다.
- **얻은 골드는 얻은 만큼 그대로 가진다.**
- 운석은 몬스터를 잡을지 운석을 부술지 **고르게 만드는 장치**가 된다. 운석을 쏘는 동안 몬스터가 내려오므로 욕심과 방어 사이의 판단이 생긴다.

**2) 단계 보상 (클리어 보상을 무한 방식에 맞게 변경, 11/26)**
- 클리어가 없으므로, **보스를 잡을 때마다** (또는 일정 웨이브를 넘길 때마다) **보상 골드를 얹어 준다.** 오래 버틸수록 많이 받는다.
- 제안: 보스 회차가 오를수록 보상도 커진다. **최고 기록을 갱신하면 추가 보너스**를 주면 기록 도전 동기가 생긴다.
- 결과 화면에서 "운석 골드 + 단계 보상 (+ 신기록 보너스) = 합계"를 나눠 보여 준다.

**운석 세부 (제안, 미확정)**
- 운석이 그냥 지나가면 **지구 피해 없음**. 골드만 놓친다. (재화를 쏘는 게 벌이 되면 안 되므로)
- 운석은 몇 번 맞아야 깨진다. 크기별로 작은 운석(1~2발, 골드 조금)·큰 운석(여러 발, 골드 많이)·드문 황금 운석(아주 많이).
- 깨지면 골드가 튀어나와 자동으로 우주선에 빨려 들어온다(줍는 조작 없음). UFO가 빛줄기로 빨아들이는 연출이 잘 어울린다.
- 경험치는 몬스터, 골드는 운석·단계 보상으로 역할을 나눈다.
- 운석은 몬스터와 모양·색이 확실히 달라야 한다(한눈에 재화로 보이게, 반짝임).
- 나중에 보상형 광고 "이번 판 골드 2배"를 붙이기 좋다(광고는 결정 전 확인).
