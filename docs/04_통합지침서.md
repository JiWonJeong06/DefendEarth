# Google Play 게임 개발 통합 지침서 (2026.11.24 기준, 코드 작업용 발췌)

> 원본: claude.ai 프로젝트 「솔로」의 「Google Play 게임 개발 통합 지침서」. 계정 절차·사용자 할 일·일정 장은 「03_개발일정」과 겹쳐 생략했다. 정책은 바뀔 수 있으니 출시 전 Play Console 정책 상태와 공식 문서를 다시 확인한다.
> 이 게임에 맞춘 결정(Unity 6000.3.29f1, 패키지명 등)은 「02_프로젝트_결정사항」이 우선한다.

## 1. 기본 원칙과 작업 방식

- **작업 분담**: 기획과 아트 프롬프트는 Cowork, 코드 개발·구현은 오직 Claude Code.
- **Claude가 멈추고 확인받는 상황**: 업로드·제출, 서명 키·비밀번호 다루기, 권한·SDK 추가, 개인정보·결제·광고 기능, Play Console 선언·설정 변경, 지침과 어긋나거나 확신이 없는 경우. 무엇을 왜 하는지 쉬운 말로 설명한 뒤 확인을 받는다. 플레이어 피해 가능성은 한 번 더 생각해서 먼저 알린다.
- **정직한 한계**: 모든 규칙을 지켜도 리젝이 없다는 보장은 없다. 문제가 생기면 내용을 정확히 읽고, 고친 빌드를 **모든 트랙**에 올리며, 이의신청은 보통 5~8일 걸리므로 일정에 여유를 둔다.
- **계정 관련 핵심**: 패키지명은 한 번 정하면 변경 불가. Play App Signing 사용, 업로드 keystore·별칭·비밀번호를 한 묶음으로 다른 장소에 백업하고 git에 올리지 않는다. 비공개 테스트 12명 이상 14일 연속 후 프로덕션 액세스 신청.

## 3. 코드와 기술 요건

새 앱·업데이트는 Android 16(API 36) 이상 타깃, 네이티브 코드가 있으면 2027-02-01까지 16KB 페이지 크기 지원. 처음부터 지원한다.

| 항목 | 요건 | 기한 |
| --- | --- | --- |
| Target API | 새 앱·업데이트 API 36 이상 | 2026-08-31 시행 중 |
| 16KB 메모리 페이지 | .so 16KB 정렬, NDK r28+, AGP 8.5.1+ | 2027-02-01 |
| 배포 형식 | AAB, 64비트 | 시행 중 |
| Android 17 대응 | 대화면 크기 조절 의무화 (API 37 타깃 시) | 태블릿·폴더블 테스트 |

### Unity 보안 규칙 (기존 앱 삭제의 교훈)

- CVE-2025-59489 패치가 포함된 Unity만 사용(6.3 계열은 6000.3.0b4 이상). 2026-10 Brotli 취약점(CVE-2026-111497)은 6000.3.27f2에서 패치 → 이 프로젝트는 **6000.3.29f1**. 시작할 때와 새 패치가 나올 때 Unity 보안 공지를 확인.
- Google은 **모든 트랙**(프로덕션·공개·비공개·내부) 중 하나라도 미패치 버전이면 취약한 앱으로 본다.

### 코딩 수칙

- 페이지 크기 4096 하드코딩 금지, `getpagesize()` 또는 `sysconf(_SC_PAGESIZE)` 사용.
- 엔진과 SDK는 최신 버전. 작업 시작 때 App Bundle 탐색기로 16KB 지원 확인.
- 매니페스트에는 꼭 필요한 Activity만 exported. 인텐트 extras·커맨드라인 인자·외부 입력은 믿지 않고 검증.
- **Development Build로 올리지 않는다.**
- HTTPS만 사용, 개인정보를 로그·PlayerPrefs 같은 평문 저장소에 넣지 않는다. 개인정보를 수집하지 않는 설계.
- 화면 방향 고정·크기 조절 차단 코드에 의존하지 않는다. API 키·비밀 값 하드코딩 금지, 릴리스 빌드 난독화.

### Unity 세로형 도트 게임 설정

- Unity Hub에서 Android Build Support(SDK, NDK, OpenJDK 포함). 빌드는 AAB, ARM64, IL2CPP, Target API 36.
- 기준 해상도 180×320(9:16), 1080×1920에 정수 배(6배).
- 스프라이트: 필터 Point, 압축 None, Pixels Per Unit 통일, Pixel Perfect Camera.
- 화면 대응: 위아래·양옆 여백을 배경으로 채우고 Safe Area 반영(자세한 규칙은 「01_게임기획서」의 「화면」).

## 4. 권한, 데이터, 타겟층

- 권한은 핵심 기능에 꼭 필요한 것만. **이 게임은 민감 권한을 요청하지 않는다**(연락처·위치·통화 기록·사진/동영상·접근성 등 모두 사용 안 함).
- **데이터 보안 섹션**: 로그인·분석·크래시·광고 SDK 수집 항목까지 실제 동작과 일치. SDK 추가·업데이트 때마다 재확인. SDK는 꼭 필요한 것만(이 게임: Google Play 게임즈는 1월, 광고는 출시 후).
- **개인정보처리방침**: 공개 URL(PDF 불가).
- **계정 삭제**: 앱에서 계정을 만들 수 있으면 앱 안과 웹에 삭제 경로. 이 게임은 자체 계정 없음(Google Play 게임즈 프로필 사용).
- **광고 ID**: 동의 없이 기기 식별자·개인정보와 연결 금지. 광고 사용 시 EEA·영국 동의 절차.
- 사용자끼리 채팅·글 기능은 넣지 않는다.
- 한국 사용자 대상이므로 개인정보 보호법도 준수.
- **타겟층**: 13세 이상. 귀여운 도트는 아동에게 끌릴 수 있으므로 그림·문구·스토어 이미지가 유아용으로 보이지 않게.

## 5. 결제, 게임 특화

- 광고: 닫기 버튼 숨기기, 예고 없는 전면광고 등 **방해성 광고 금지**.
- 콘텐츠 등급: IARC 설문을 사실대로(몬스터 처치·폭발 표현).
- **확률형 아이템(뽑기) 넣지 않는다.** 실제 돈이 걸린 요소 없음.
- 안정성: Android Vitals 크래시율·ANR 관리. 실제 안드로이드 폰으로 테스트.

## 6. 스토어 등록정보와 콘텐츠

| 항목 | 규격 |
| --- | --- |
| 앱 아이콘 | 512×512 px, 32비트 PNG(알파 포함), 1024KB 이하. 순위·가격 배지, 오인 문구 금지 |
| 피처 그래픽 | 1024×500 px, JPEG 또는 24비트 PNG(알파 없음) |
| 제목 | 30자 이하 |
| 짧은 설명 | 80자 이하 |
| 긴 설명 | 4,000자 이하 |
| 스크린샷 | 실제 앱 화면, 세로형 |

- 사칭 금지, 유명 게임의 이름·그림·규칙을 그대로 따라 하지 않는다.
- 폰트·효과음·배경음은 라이선스 확인 및 근거 보관(폰트는 한·영·일 지원).
- 출시 전 앱 콘텐츠 선언 모두 완료: 개인정보처리방침, 광고 포함 여부, 앱 액세스, 콘텐츠 등급, 타겟층, 데이터 보안, 광고 ID.
- 업로드 직후 정책 상태 화면에 새 경고가 없는지 확인. 사전 출시 보고서 활용.

## 7. 기존 앱 교훈과 재발 방지

기존 앱 「항해하는 갈매기」는 보안 취약점(기기 및 네트워크 악용 정책 위반, Unity CVE-2025-59489로 추정)과 Target API 미달로 2026-06-10 삭제됐다. 고친 빌드를 올리지 않았고 이의신청도 하지 않았다.
→ 패치된 Unity로만 빌드, targetSdk 36 이상, 새 패키지명(`com.kkangjung.bouncyufo`), 업로드 후 정책 상태 확인, 경고가 오면 바로 고친 빌드를 모든 트랙에 올린다.

## 10. 출시 전 체크리스트

- [ ] targetSdkVersion 36 이상, AAB·64비트·IL2CPP 빌드
- [ ] Unity 버전이 보안 공지의 패치 버전 이상인가, 올린 모든 트랙이 패치본인가
- [ ] 16KB 페이지 지원 확인 (App Bundle 탐색기, 플러그인 포함)
- [ ] 릴리스 빌드인가, 매니페스트에 불필요한 exported Activity가 없는가
- [ ] 불필요한 권한 없음
- [ ] 데이터 보안 섹션이 SDK 수집 항목까지 반영 (Google Play 게임즈 포함)
- [ ] 개인정보처리방침 URL 접속 확인
- [ ] 타겟층 선언이 정확하고 그림·문구가 대상 연령과 맞는가
- [ ] 콘텐츠 등급 설문·광고 포함 여부(첫 출시: 아니요) 선언 완료
- [ ] 스토어 아이콘·피처 그래픽·스크린샷·설명 규격 확인 (한·영·일)
- [ ] 업로드 키 백업 완료, keystore가 git에 없는가
- [ ] 비공개 테스트 12명·14일 완료, 프로덕션 액세스 신청
- [ ] 개발자 인증·판매자 상태 선언 완료, 휴면 계정 경고 해제
- [ ] 사전 출시 보고서·정책 상태 확인, 단계적 출시로 배포
