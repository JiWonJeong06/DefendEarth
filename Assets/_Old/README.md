# _Old (참고용, 나중에 삭제)

기존 DefendEarth(Unity 6000.3.10f1) 코드·장면·프리팹·그림. **참고만 하고 새 게임에서 쓰지 않는다.**

- 빌드 장면 목록에서 뺐다 (EditorBuildSettings).
- 스크립트는 `OldDefendEarth.asmdef`(Editor 전용, 자동 참조 끔)로 묶어 게임 빌드에 들어가지 않고 새 코드와 이름이 겹치지 않는다.
- 원래 `Assets/Resources`는 `OldResources`로 이름을 바꿨다(Resources 폴더는 무조건 빌드에 포함되기 때문).
- 폰트(DOSPilgi, Ramche)·배경음(DefendEarth.mp3)은 출처·라이선스 확인 전 사용 금지.
- 쓸 만한 그림(UFO·적·지구)은 새 폴더로 복사해서 Point 필터·압축 None·PPU 통일로 다시 설정해 쓴다.
