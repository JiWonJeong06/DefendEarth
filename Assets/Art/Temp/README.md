# 임시 그림 (옛 DefendEarth에서 복사)

첫 빌드용 임시 그림. 새 도트 그림이 나오면 교체하고 삭제한다.

- `Enemy.png`: UFO 3종 + 몬스터 (32×32 칸)
- `Earth-Star.png`: 지구·별·배경 (64×64 칸)
- 설정 통일: 필터 Point, 압축 None(모든 플랫폼), Pixels Per Unit 16, 밉맵 끔
- 기준: 플레이 영역 180×320 픽셀 = 11.25×20 유닛 (PPU 16)
- 새 그림도 모두 **PPU 16**으로 맞춘다.
